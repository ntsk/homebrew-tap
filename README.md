# Homebrew Tap

Personal Homebrew tap for ntsk's projects.

## Installation

```bash
brew tap ntsk/tap
```

## Formulae

| Formula | Description |
|---------|-------------|
| [rss](https://github.com/ntsk/rss.rs) | A simple RSS/Atom feed reader for the terminal |

### rss

```bash
brew install ntsk/tap/rss
```
